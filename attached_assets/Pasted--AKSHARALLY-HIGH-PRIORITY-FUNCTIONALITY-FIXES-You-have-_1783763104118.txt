# ISSUE 3: READER SCREEN TEXT FORMATTING BUG

## Root Cause Identified

The current ReaderScreen:

* Splits text by spaces
* Renders each word as a separate Text widget
* Uses Wrap

The backend returns text containing:

```text
\n
\n\n
```

These newline characters remain embedded inside individual words.

This causes:

* Broken lines
* Floating words
* Huge spacing gaps
* Poor Hindi rendering
* Poor paragraph rendering

---

## Required Fix

Implement proper paragraph rendering.

Before rendering:

1. Detect paragraph breaks
2. Separate paragraphs correctly
3. Preserve paragraph structure
4. Remove embedded newline rendering issues

The rendered output must:

* Display complete paragraphs properly
* Maintain word highlighting
* Maintain TTS compatibility
* Support Hindi
* Support Marathi
* Support English

Avoid:

```dart
Wrap + broken newline tokens
```

Implement a clean solution.
