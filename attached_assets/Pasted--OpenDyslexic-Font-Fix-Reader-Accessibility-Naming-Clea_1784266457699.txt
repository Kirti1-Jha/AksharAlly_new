ISSUE 2 — IMPROVE READER AID LABELS
========================================================

This is a small UX improvement.

The verification report confirmed:

Focus Line Mode

is NOT automatically tracking the active reading line.

Instead:

The user manually drags a focus band.

This is still a useful dyslexia aid.

However:

"Focus Line Mode"

implies automatic line tracking.

The implementation is actually a:

manual reading focus window.

========================================================
REQUIRED CHANGE
========================================================

Rename:

Focus Line Mode

to:

Focus Window

or another name that accurately reflects the existing implementation.

Do NOT change functionality.

Only improve wording.
