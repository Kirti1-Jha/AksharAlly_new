========================================================
ARCHITECTURE RULES (MUST FOLLOW)
========================================================

AksharAlly currently has two separate accessibility systems.

--------------------------------------------------------
UI Accessibility System
--------------------------------------------------------

Managed by:

UIAccessibility

Purpose:

Application-wide UI personalization.

Controls:

- HomeScreen
- LibraryScreen
- Accessibility Center
- App colors
- App typography
- Navigation labels
- General UI appearance

--------------------------------------------------------
Reader Accessibility System
--------------------------------------------------------

Managed by:

AccessibilitySettings

Purpose:

Reader content personalization.

Controls:

- OutputScreen
- HighlightedTextView
- Reading Customize Sheet
- Reading profiles
- Reading themes
- Reading aids

These systems are intentionally separate.

DO NOT merge them.

========================================================
PART 1 — HOME SCREEN CLEANUP
========================================================

PROBLEM

The Home screen currently contains:

Library → View All

card near the bottom.

However, Library already exists in the bottom navigation bar.

Current navigation:

Bottom Navigation
→ Library

AND

Home Screen
→ Library Card

Both lead to the same destination.

This is redundant and creates unnecessary visual clutter.

--------------------------------------------------------
REQUIRED CHANGE
--------------------------------------------------------

Remove the entire Library card section from HomeScreen.

Remove:

- Library card
- View All link
- Any widget used exclusively for that card

Keep:

- New Reading card
- Reading Statistics card
- Continue Reading section
- Bottom navigation

--------------------------------------------------------
EXPECTED RESULT
--------------------------------------------------------

Cleaner Home screen.

Less visual clutter.

Library accessed only through bottom navigation.

--------------------------------------------------------

--------------------------------------------------------
