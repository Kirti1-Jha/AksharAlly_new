Users can:

* Upload images
* Upload PDFs
* Upload documents
* Extract text using OCR
* Format text for dyslexic readers
* Simplify text
* Use text-to-speech
* Follow highlighted words while reading
* Save documents in library
* Manage accessibility settings

Backend is built using Flask.

Frontend is built using Flutter.
